HouseParty
A collaborative Spotify music queue built with SwiftUI.

Features
- Create and join music sessions
- Spotify integration and playback control
- Collaborative track queue
- Upvote and downvote tracks
- Real-time synchronization using Firebase Firestore
Tech Stack

Swift · SwiftUI · Firebase · SpotifyAPI · KeychainAccess

Note

This is a portfolio showcase. Sensitive configuration and backend credentials are intentionally excluded.
